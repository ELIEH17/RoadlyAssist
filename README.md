# RoadlyAssist

React + TypeScript prototype for a Lebanon-focused roadside assistance and garage management platform.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Current prototype flow

- Choose roadside service
- Use browser GPS or enter a location manually
- Browse demo nearby providers
- Select a provider
- View request confirmation / tracking prototype
- Preview garage management dashboard

Provider availability, distance, ETA and tracking are demo data in this prototype. Browser GPS coordinates are real when permission is granted.
